# Login test plan

Environment: staging · Role: user · Test type: both

## Risks

| ID  | Risk                                                                                                        | Impact | Likelihood | Level  |
| --- | ----------------------------------------------------------------------------------------------------------- | ------ | ---------- | ------ |
| R1  | A configured user cannot authenticate or receive a usable bearer token, blocking access to the application. | High   | Medium     | High   |
| R2  | Login accepts missing or invalid credentials and grants unauthorized access.                                | High   | Low        | Medium |
| R3  | A server-side login failure leaves the user without clear feedback or a way to retry.                       | Medium | Medium     | Medium |
